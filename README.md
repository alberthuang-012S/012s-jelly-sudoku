# 012S Jelly Sudoku｜水母數獨

區域型邏輯益智遊戲：在 N×N 盤面放 N 隻水母，每橫排、每直列、每個顏色區域各一隻，水母周圍八格不可放另一隻。

## 開發與驗證

使用 Node.js 24 以上。

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

正式版預設 base 為 `/012s-jelly-sudoku/`，可用 `VITE_BASE_PATH` 調整。

## 關卡目錄（revision 5）

6×6 基礎、8×8 普通、10×10 挑戰各 100 關，共 300 關。每種盤面分 10 章，每章 10 關，完成目前關卡後解鎖下一關。

所有正式題都通過連通性、配色、完整解答、唯一解及無猜測推理驗證。去除旋轉、鏡射與換色的同題；每關與前 10 關比較，經八種旋轉／鏡射及最佳顏色對應後，區域布局相似度不得超過 85%，答案排列不可相同。同一生成來源在近距離最多兩題，第一個突破口不連續落在同一盤面區段。

難度改為每章平均分數嚴格遞增，章內交錯技巧，單關分數不再強制遞增。基礎前五關熟悉唯一位置，第六關開始直線，前二十關涵蓋相鄰兩格與三格直線。普通前十關涵蓋直線、反向鎖定、兩格、三格與 L 形，第三章開始穿插三色鎖定。挑戰前十關已有四題需要多色鎖定，第二章開始三色鎖定，第五章開始穿插兩區組合，最後二十關仍需兩區組合推理。這是結構上的難度指標，尚未用玩家完成時間校準。

提示引擎前三個排除步驟組成解題路徑標記，除最初五題唯一位置練習外，不連續重複相同標記，近距離最多三題使用同一標記。這比較的是共用引擎的路徑，並非限定玩家只能按這個順序解題。`src/game/diversity.ts` 提供布局與路徑比較；`scripts/catalogue-audit.json` 記錄選題來源、路徑、突破口區段、各章平均分數及相似度上限，測試會重新核對這些條件。

```bash
npm run generate:levels
```

`scripts/generate_catalogue.mjs` 用固定亂數種子、歷史開局資料及相同的 TypeScript 推理引擎離線生成、篩選與排序關卡。新來源重新產生答案、形狀及區域；衍生題包含邊界調整與通過連通性檢查的行列重排，仍受來源與相似度限制。生成途中不修改正式資料，全部成功後才寫入 `src/data/levels/generated-levels.json`。頁面載入只讀靜態資料，不執行生成器。

候選池保存在被 Git 忽略的 `node_modules/.cache/jelly-catalogue-v5.json`，調整選題時可用 `npm run generate:levels -- --reuse-pool` 重用候選並重算提示分類；不帶此參數會重新生成。來源相同的衍生題不因行列重排而視為新來源。

`scripts/catalogue-seeds.json`、`scripts/normal-seeds.json` 與 `scripts/fresh-layout-seeds.json` 是固定種子來源；後者保留本次從新答案與新區域生長取得的十八個獨立盤面。衍生題的父題採來源均勻抽樣，避免某一來源因候選數多而占據選題池。舊 Python 生成指令已轉接到整份目錄生成流程。

## 推理與提示

`src/game/logic.ts` 提供單一共用引擎：唯一位置、直線鎖定、反向鎖定、相鄰兩格、三格直線、L／Z 形、共同禁區、雙色／三色鎖定、兩區合法組合排除。每一步包含觀察方向、候選來源、排除或放置目標與中文理由；推理從不讀取儲存的 `solution`。

提示分成「觀察方向 → 解釋理由 → 顯示結果」，同一步合計消耗一次。顯示結果後可由玩家套用；修改盤面會清除過期提示。玩家的叉號與水母先用獨立邏輯證明確認，再作為提示前提；不一致時標示待修正位置，不扣提示。作答途中不自動判定對錯，提交或主動要求提示時才檢查。

## 定石教室

保留原本 4×4 操作教學，完成後可選「學習定石」進入基礎課程，或「開始基礎第一關」；從教學進入定石教室後，離開會返回首頁。另有 9 個可隨時重看的定石課程，分為三種可自由選擇的學習難度，每級顯示學習進度，不必依序解鎖：

- 基礎：直線、相鄰兩格、三格直線。
- 進階：轉一個彎、Z 型、這一排。
- 挑戰：雙色雙排、三色三排、兩區合法組合。

每課使用兩個正式關卡盤面，示範、比較與練習皆直接顯示完整盤面，保留實際顏色與已放好的水母。先前已排除的叉號隱藏，排除資料仍保留供推理使用；圈圈表示本課顏色剩下能住的位置。示範只顯示該步新推導的叉號，結論只保留共同排除的位置；小練習不顯示叉號，只保留線索圈圈、水母與問號。比較使用同一張盤面切換「位置 1／位置 2／共同禁區」，L 形多一個位置 3，切換與進入練習時盤面位置保持一致。電腦以選課、盤面與解說分欄；手機選課收成可展開的換課選單，主要操作固定在底部，橫向時改用左右分欄。遊戲提示連到定石教室時，自動選中對應難度與課程。

示範每 3.5 秒前進一步：先圈候選位置，讓水母逐個試住，最後可切換各位置比較共同叉號。多色多排先展示兩種安排，再解釋顏色數與排數相同的原因。L 形示範包含凹角與彎角外側兩格，逐格標明同排、同列或相鄰的排除理由。兩色組合課程以反證呈現：單看一色不能排除的格子，假設放水母後會迫使兩色擠同排或同列，所以該格能畫叉，適合基本技巧卡住時再用。支援暫停、上一步、下一步及重播；系統偏好減少動態時預設暫停。練習每次只問一個問號格能否確定畫叉，答錯可重試；完成兩個不同盤面的判斷才記為學會，之後可展開誤用提醒。

完成紀錄存於 `jellySudokuAcademy.v1`，與正式關卡分開。教室不計時、不扣提示；從遊戲進入時暫停遊戲計時，返回後保留盤面及提示。`npm run generate:teaching` 用同一推理引擎從正式關卡擷取教學例子，寫入 `src/data/teaching-scenes.json`。

兩格定石固定側邊排除四格，三格直線排除中心兩側。共同禁區仍是推理引擎的能力，教室取消其獨立課程。L／Z 外形有額外候選格時不可直接套用，靠邊界時可畫叉的格數可能減少。移除課程的學習紀錄保留在儲存資料中，不計入現有課程總數；不再顯示對應的失效提示連結。

## 進度與相容性

正式進度仍使用 `jellySudokuSave.v1`，解鎖上限為 100。保留既有完成與解鎖進度，舊版已完成前 10 關會自動開放第 11 關；revision 4 及更早版本的未完成盤面因布局重建而重置；最佳紀錄依 `關卡 ID@revision` 分開保存，既有紀錄保留。原操作教學仍使用 `jellySudokuTutorial.v2`。

## 結構

- `src/game/`：規則、唯一解求解器、推理引擎與驗證。
- `src/data/levels/`：300 關靜態目錄。
- `src/data/lessons.ts`、`teaching-scenes.json`：9 課教學規則與 18 個正式盤面例子。
- `src/components/AcademyScreen.tsx`：定石教室。
- `src/storage/`：存檔、解鎖、版本與最佳紀錄。
- `src/App.tsx`、`src/styles.css`：首頁、章節、盤面與三段提示。
